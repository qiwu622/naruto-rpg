联机重新开放｜战术战斗｜存档减负｜安卓云端｜记忆纠错

🤝 联机重新开放

  • 顶栏恢复 联机入口，可以进入房间历史、重连上次房间。
  • 大厅、创建 / 加入房间、房间历史、开局、聊天、角色资料与退出确认统一为 深墨色＋暖金色 风格。
  • 优化桌面、手机和窄浮窗的布局、表单、按钮与状态提示，支持键盘切换标签和调整窗口。
  • 悬浮窗支持 拖动、缩放、收起、归位，改善手机安全区与快速缩放；输入时若挡住输入框，会自动收起。
  • 补全模型对物品新增、消耗、装备与移除的格式说明，减少反复修正。

⚔️ 可选战术回合战斗

在顶部「战斗」或设置中手动开启。默认仍以正文游玩。

  • 沿用角色已有忍术、属性与背包，本地结算先制、命中、伤害、查克拉消耗和持续状态，再由正文演绎结果。
  • 查克拉上限参与忍术输出，剩余查克拉用于支付消耗；资源不足时可尝试弱化施术。
  • 全新月夜战场、象牙纸色指令区与朱红确认按钮，支持 4 个自定义快捷招式、招式预览、忍具、自由行动与战报。
  • 开启后由 AI 根据实际交锋登记战况；攻击词不会直接触发开战，未交锋时显示等待状态。
  • 关闭面板同时停用面板专用提示词；玩家自定义预设保持原样，已记录战况会保留。
  • 修复防御 / 观察 / 撤离被误认作自由战术；结算随正文与记忆一起保存，失败回滚，重试保留原判定；切磋失去作战能力不再自动死亡。

📚 存档减负与云同步

  • 存档库新增 「轻量续玩副本」：自选保留回合数，先保留原档，再创建所选线路的近期正文、日报与回退点副本。
  • 历史记忆与角色关系继续保留，不会自动切换当前游戏；副本可继续游玩、创建 IF 线、导入 / 导出及上传 / 下载云端。
  • 本地和云端卡片展示轻量副本的正文与回退范围，避免误以为包含全部历史。
  • 修复安卓和网页导出大存档时误报 「解压后超过 200 MiB」；直接导出已保存的完整文件，保留节点、IF 线和校验信息。
  • 优化大档历史节点处理与分块序列化，降低导出时的内存峰值。
  • 云同步显示进度、失败与重试入口；遇到版本冲突可 保留双方副本，避免静默覆盖其他设备的进度。
  • 切换存档或账号时取消旧同步队列，修复旧上传完成后错误提示最新进度已同步。

📱 安卓接入现有云端账号

  • 在 个人中心 / 存档库 启用云端，通过系统浏览器核对连接码并授权，继续使用网站现有账号。
  • 安卓联机使用原生云端请求与实时事件连接，未登录时引导连接账号，保留本地进度。
  • 云端账号、存档管理与同步共用网页功能，提供连接状态、重试、暂停和退出账号入口。
  • 云端检查后台执行，列表加载不锁住本地操作；断网、超时或登录失效仍可保存、读档和操作本地游戏。
  • 回合先保存在本机；已开启自动同步 时，连接恢复后继续备份待同步进度。
  • 登录凭证由 Android Keystore 加密保存，不进入游戏存档或导出文件。
  • 云端服务可选；模型生成仍需要玩家配置的 AI 接口及网络连接。

🧠 记忆、变量与回合反馈

  • 正文下新增可折叠 「回合结果」，查看变量、记忆、日报、本地保存结果，以及实际记录的阶段耗时和重试次数。
  • 回执随节点保存，回看历史可查看；旧档缺失记录时明确显示未记录。
  • 记忆面板支持 搜索、查看来源、纠正、否定、置顶和撤销；修订影响当前线路后续检索与摘要，原历史节点保持原样。
  • 在已有后续的旧节点修订记忆时，会保留原线路并创建 IF 线。
  • 未选择的行动选项不再被当作已发生事件 写入正文上下文、变量更新、Agent 检索和本地记忆；界面仍显示选项。
  • 修复同回合物品获得、消耗、移除与重建的顺序，避免误扣数量或误删整个物品。
  • 恢复置顶记忆与相关事实读取；深度整理保留未送入本次模型的条目及未处理的关系历史。

🔥 NPC 成长与灵希修复

  • NPC 成长不再被忍阶基准截断；明确恢复时可正确恢复当前资源，更新单个忍术或查克拉属性不再覆盖其他能力。
  • 档案刷新最新战斗属性、忍术和综合战力，保留滚动位置与肖像操作；后续交战使用最新档案。
  • 修复生成、变量更新或后台人物摘要期间切换存档 / 节点 / IF 线后，旧结果写进新进度的问题。
  • 灵希切档时停止旧请求、清理本轮未确认提案；兼容模式复用相同工具操作结果，减少重复执行。
  • 修复灵希浮窗重新打开后消息、提案和流式回复不刷新，以及已执行操作却显示未修改的问题。

💰 DeepSeek 专用适配

在 API 设置选择 「DeepSeek 专用 · 缓存优化」，默认关闭。

  • 仅开启后调整项目动态事实与检索记忆的位置，保留稳定规则前缀；未开启时沿用原有上下文组成、消息顺序与推理参数。
  • 支持关闭 / 低 / 高 / 最高思考档位，随 API 方案保存；网页、安卓、变量更新与 Agent 共用适配。
  • 不删减正文、历史记忆或玩家预设；缓存效果取决于实际请求和供应商返回数据。
  • 增加缓存命中、未命中与思考 token 统计，设置页可查看最近用量报告；专用模式普通正文空回复不再自动付费重发。

✨ 界面与输入

  • 新增 网站更新公告页，登录页与游戏设置可查看本次完整公告及历史版本；此后正式更新会同步网站公告。
  • 精修正文阅读遮罩、顶栏、侧栏、属性分区、朱红按钮和手机输入区；保留字体、文字配色与自定义背景设置。
  • 装备品质、玩家 / NPC 忍阶、忍术与任务等级新增 沿轮廓移动的分级流光；高阶增加扫光，支持系统减少动态效果。
  • 统一回合结果卡、云同步状态与记忆卷宗样式，改善窄屏阅读、冲突操作与键盘交互。
  • 输入框旁新增 「回车发送 / 回车换行」 切换，记住本机选择；Shift + Enter 换行，Ctrl / ⌘ + Enter 发送。
  • 修复中文输入法选字误发送、组合快捷键重复发送和角色面板关闭无响应。
  • 修复 API 设置下拉菜单错误向上展开、遮挡相邻选项的问题。

🛠️ 稳定性修复

  • 修复部分导入预设的展示正则将正文清空后，变量更新完成时 正文消失、只剩思维链和日报 的问题；展示为空时回退到清理后的正文。
  • 改善联机 SQLite 原生驱动回收稳定性，补充压力回归；自部署环境要求 Node.js 22+，已有数据库格式保持兼容。
  • 改善发布包校验、后端就绪检查、失败恢复与测试站独立更新流程。

📥 更新与存档说明

灵希 Agent 助手

  • 新增独立灵希助手、角色动画、可拖动宠物与桌面对话框、新开对话确认以及有界上下文；可单独选择已保存的 API 方案，且不会把密钥写入模型消息或会话存储。

  • 剧情、开局和世界书相关生成必须在同一轮先完成对应检索；检索结果必须与用户请求或当前项目证据相关，未检索或检索不相关时拒绝提交内容。
  • 新增设置、变量修复、开局、人设、世界书、剧情方向、装备、物品、任务、普通行动、战斗动作、时间线、云存档、图片生成和图库操作适配器。
  • 少量、可逆、无费用的白名单设置可后台应用；删除、覆盖、剧情推进、开局初始化、云存档和外部生图等操作必须显示精确影响并由确认界面点击批准，不再要求手动输入 yes。

音乐与媒体

  • 新增腾讯音乐目录搜索与本站同源音频代理，移除酷我渠道；代理校验歌曲标识、重定向目标、响应大小和音频类型，避免 Mixed Content 与直接跨站播放问题。
  • 播放前使用 Range 请求和音频文件头预检。候选不可播放时先尝试同歌其他版本，再自动换歌；浏览器手势拦截不会被误判为坏歌。
  • 灵希打开歌曲后自动显示默认缩小的音乐悬浮窗，支持拖动、展开、关闭、上一首、播放/暂停和下一首，整个过程不再打开设置面板。

叙事与 Agent 管道

  • Agent 模式调整为“场景节拍 → 详细写作大纲 → 多重终审 → 最终正文 → 连续性结算”。终审前禁止生成正文，正文定稿后不再交给未审查的润色模型改写剧情结构。
  • 新增结构化写作大纲、角色决定来源校验、玩家行动边界、自然停止点、变量证据和最终完整性审计，并支持可检索的时间、记忆、正史与世界书一致性审查。
  • 加强阶段缓存与失败续跑、工具结果预算、流式事件和兼容降级，减少重试时重复调用与超长工具结果挤占上下文。
  • 严格单模型提示词明确要求推理块先闭合、机器标签只放正文之后，并给出唯一 <state_update> 的固定格式，降低偶发漏标签和截断导致的整回合失败。

时间线、剧情方向与领域操作

  • 新增按分支保存的未来剧情方向，可设置目标、禁区、节奏、角色羁绊、伏笔与条件分支；方向变化会使旧规划失效并触发重新规划。
  • 加强时间线维护检查点、分支切换、主线升格、IF 分支删除、重推衍和并发状态校验；过期提案会在写入前失效，失败操作可回滚且不覆盖同时发生的新提交。
  • 装备、消耗品、任务和战斗操作统一通过真实领域系统结算，避免绕过数量、属性加成、奖励、统计和时间线记录。

平台、缓存与稳定性

  • 服务端 AI 代理新增可配置的上游 429 重试预算，完善流式中断、并发准入、响应上限和后端健康检查。
  • Service Worker 对 API、认证、非 GET 和代码模块执行明确的缓存旁路或重新验证；测试站 Nginx 对 JS/CSS/MJS 和 sw.js 禁用陈旧缓存。
  • 新增灵希逻辑回归、浏览器交互回归、音乐代理回归、剧情方向回归和 Service Worker 缓存回归，并纳入统一测试命令。

兼容性

  • 现有本地存档、云存档、世界书、自定义预设和图片资产继续兼容，无需重新开档。
  • 音乐只保留腾讯目录；已保存的酷我来源不会再被解析。
v3.1.02026-08-06

Agent 模式核心升级

  • 并发与稳定性：Agent 并发上限提升到 10(可配置),角色代理并入有界并发闸门;服务端 AI 代理并发闸门可配置(默认每用户 10/全局 32),不再被自己的限流打成 429。
  • 思维链可视化:捕获 DeepSeek reasoning_content/Claude thinking,主模型思维链内联展示,子模型推演面板可点击查看每个子代理的思考过程、完整输出与工具步骤;流式时保持展开、按 500ms 刷新。
  • 写作解耦:主模型(Writer)只输出正文,变量/记忆/日报由后续二次变量更新与专属的连续性更新代理产出(人物关系含心理 inner_thoughts 与历史 history);正文 900-1500 字、文风遵循预设。
  • 审查与修复闭环:大纲审查发现问题自动重生成;终审通过才提交,审查不通过才触发一轮修复重写并复审;新增可搜索的剧情合理性审查(时间/记忆一致性)。
  • 阶段断点续跑:某环节失败重试时,从失败阶段直接续跑,复用上方已完成的正确环节,不再重走全流程。
  • 工具兼容降级:模型不支持工具调用时,自动降级到无工具普通对话,不再报 404 中止。
  • 提示词缓存优化:稳定前缀前置(证据/约束后置),适配 DeepSeek 自动前缀缓存;面板显示缓存命中率。

新功能

  • 多 API 方案:设置面板与开局契约可保存/切换多套 API 地址/密钥/模型。
  • 人设方案:开局向导可保存多份人设、开局前切换;个人中心可查看/删除已存人设。
  • AI 不再自动超时:文本生成由用户手动停止;nginx 反代 /api 超时放宽。

修复

  • 角色代理不再拉入陌生/不在场 NPC(仅已认识、战斗敌人或玩家点名)。
  • 思维链 100% 误显示、子代理展开被打断、"缺少可见正文"误报、记忆/日报缺失导致整回合失败等问题。
