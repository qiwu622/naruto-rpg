# 火影世界书

这个文件夹保存项目可直接读取的世界书资料。

文件说明：

- `timeline.js`：火影主时间线目录，包含远古、战国、忍界大战、木叶48年、原作第一部、疾风传、战后新时代。
- `timeline-detailed.js`：更细粒度的木叶纪年、忍界大战、村内事件、外交事件和篇章节点。
- `era-consistency.js`：当前时间线判定与年代合理性规则，防止把疾风传、原作第一部或战后结果倒灌到玩家当前年代。
- `arcs.js`：原作主要篇章目录，包含第一部、卡卡西外传、疾风传前后半与战后结构。
- `characters.js`：重要角色摘要，覆盖木叶、砂隐、雾隐、岩隐、云隐、晓、大筒木、尾兽等关键人物。
- `character-details.js`：角色性格、说话方式、动机、弱点、行为边界与木叶48年状态细化。
- `character-details-2.js`：第二批角色细节，补充尾兽、人柱力互动、晓搭档规则和时代一致性。
- `character-appearances.js`：角色外观、服饰、辨识点和场景描写辅助资料。
- `expanded-characters.js`：扩展 NPC、人柱力、尾兽、家族成员、小国与日常地点。
- `locations-organizations.js`：忍村、组织、家族、能力体系资料。
- `shinobi-roster-2.js`：忍者名册扩展，补充更多角色、阵营、年龄阶段和出场边界。
- `boruto-era.js`：博人传/新时代资料；默认木叶48年主线只作为远期背景或新时代团资料。
- `world-expansion.js`：火之国地理、木叶日常地点、低阶任务、小国、经济、情报公开等级等跑团常用补充。
- `systems.js`：查克拉、性质变化、忍术等级、瞳术、封印术、医疗、幻术、傀儡术等系统资料。
- `index.js`：统一导出入口，供 `knowledge-base.js` 合并检索。
- `schema-v2.js`：Worldbook V2 规范化、校验、日期/知识边界、角色档案和运行时安全投影。
- `migration-v2.js`：逐条迁移旧世界书，记录稳定 ID、原始来源、重名处置与片段净化报告。
- `v2.js`：V2 公共 API 入口。

## Worldbook V2 使用约束

- 写作、变量更新和 NPC 上下文只能使用 `toRuntimeWorldbookEntry()` 或 `WORLD_BOOK_V2_RUNTIME_ENTRIES`，不得直接序列化 `WORLD_BOOK_V2_ENTRIES`；后者含迁移审计需要的旧原文。
- `validity.until` 为不包含边界。例如木叶 51—63 年迁移为 `from=K051-01-01`、`until=K064-01-01`。
- 旧角色条目会保留身份、性格、目标、弱点、说话方式、行为边界、安全外貌和年代状态。受污染的具体外貌段单独隔离，不会因此删除整名角色。
- 旧自定义条目通过 `migrateCustomWorldbookEntriesV1ToV2()` 迁移为 `legacy_trusted_public`；这只是知识来源标记，不得改变启用开关或触发模式。关闭和隔离状态优先于常驻。
- `activation.js` 统一导入与触发语义：绿灯需命中主关键词，并满足启用的次关键词条件；蓝灯可无关键词；手动条目不自动注入。标题和正文相似度不能替代自定义条目的关键词命中。同名自定义条目不合并内容。
- 自定义条目（包括蓝灯）和内置可选条目共享 `maxEntries` / `budget` 上限；预算按序列化字符计，单条超长也不能越限。固定内置核心规则使用原有保留空间；`budget_used_chars` / `budget_skipped_ids` 用于诊断。
- 旧版本导入时已丢弃的蓝灯标记或次关键词条件无法推断。缺少模式的条目按绿灯解释；用户可在编辑器设置模式或重新导入原文件。关闭状态和已有主关键词在加载时直接生效。
- `source_fragments` 保存每个 V1 片段的原文和明确处置，仅供编辑器迁移审计，禁止进入模型提示词。

写作原则：

- 使用原创摘要，避免复制百科原文。
- 以跑团可用性优先，强调人物当前时代状态、可用支线、避免过早剧透。
- 默认游戏时代为 `木叶48年`，但玩家可以通过角色设定、存档、时间线跳跃或明确选择进入其他年代。若世界书中人物在当前时代尚未活跃，应由 AI 按当前时间线处理，不得默认玩家处于疾风传开始。
