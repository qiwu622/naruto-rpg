# 本地存档库与房间历史改造方案

日期：2026-09-29

## 要解决的问题

个人游戏只有一份工作时间线。原先重新开始会清空它，文件导入默认走覆盖或合并，没有独立的多档目录。联机仅记录最后一个房间 ID，没有各玩家自己的房间历史和退出保存选项。

本次将“工作进度”和“保存的副本”分开，并将个人存档与联机房间分区。保留既有时间线、分支、压缩 codec 和服务端 Room/Epoch/Checkpoint 机制，不让浏览器存档覆盖联机权威状态。

## 本次实现范围

| 功能 | 规则 |
| --- | --- |
| 存档入口 | 顶栏“存档”、设置中的“本地存档库”；联机建房面板显示最近房间及完整历史入口 |
| 退出房间 | “保存并退出”“仅退出”“取消”；写入成功后才断开；保存失败保持房间连接并显示原因 |
| 房间历史 | 每次连接记录房间号、席位、阶段、最近回合；仅退出也保留历史，不覆盖已有快照 |
| 联机快照 | 保存当前账号从服务器获得的最新已提交回合投影：正文、日报、可见变量、检查点引用；未开局房间也可保存连接信息 |
| 重新进入 | 原站点、原账号重新鉴权，从服务器恢复原房间的最新进度；不会将旧快照上传覆盖服务器 |
| 个人多档 | 每次手动保存新增一份完整时间线副本；保留所有分支、正文、记忆与日报；自动备份相同内容去重 |
| 开新档 | 先备份当前时间线；备份完成后原子清空工作时间线并创建新角色；已有库中旧档保持不变 |
| 读取旧档 | 先完整校验目标文件与状态，再备份当前进度，最后替换工作时间线；生成中或联机中不能切换个人档 |
| 导入 | 只新增库条目，不改变当前游戏；旧 JSON、JSON.gz、gzip 以及现有服务端个人单机导出继续兼容 |
| 导出 | 每份档独立导出，支持 gzip 自动压缩；不包含 API 密钥、密码或登录凭证 |
| 改名和删除 | 支持改名；删除需要确认，仅删除该本地副本，不删除工作进度或服务器房间 |

## 存储和格式

- 新建独立 IndexedDB `naruto_rpg_save_library` v1：`entries` 目录与 `files` 压缩文件在同一事务中提交。
- 旧 `naruto_rpg` 中的时间线继续作为当前工作进度。首次打开库时保留兼容副本；即使没打开过库，读档和开新档前也强制备份。
- 个人档 `personal_timeline` 按本设备存放，沿用旧个人进度的设备归属。联机档 `multiplayer_room` 按当前登录账号与原站点区分。浏览器本身也按站点 origin 隔离存储。
- 文件信封 `naruto.save-package/v1`：`kind`、`saved_at`、`label`、`checksum`、`payload`。SHA-256 用于意外损坏检测，不代表服务端签名或房间所有权证明。
- 元数据与正文分开读取，列目录不解压所有大档。导入沿用现有解压后 200 MiB 限制。文件校验、快照恢复校验在替换工作进度之前进行。
- 配额失败、事务失败、文件损坏、未知版本均给出错误；不静默删除旧档，不在失败时继续清空当前进度。

## 联机边界

每位玩家保存各自获准接收的投影。存档文件不包含对方未公开的私密数据，也不包含房间密码或模型凭证。导入另一账号的联机文件会提示登录原账号；来自不同站点的文件可保留查看，但重新进入须在原站点执行。

本地联机快照是最新一次已发布回合的个人可见记录与房间入口，不是完整服务器数据库备份。服务器删除房间后仍可查看本地快照，但不能仅凭一个人的文件重新建立双人权威世界。需要离线迁移服务器房间时，应另做双方授权、服务器签名检查点和新 Room/Epoch 导入流程，不能假装本地缓存已具备这个能力。

## 兼容和后续阶段

1. 本次先完成本地多档和联机历史。旧文件继续能导入；工作时间线不会因升级而被清空。原有个人单机导出保留其非 Agent 谱系元数据。
2. 2026-09-30 已扩展为统一存档库中的云端管理：可选择个人档上传到新槽位或覆盖已有槽位，列出、下载、读取、改名及备份后删除云档。自动同步仍只使用「默认云存档」槽位，不会批量上传整个本地库。完整 IF 线随个人档保存；联机房间快照继续保存在各玩家本机。接口与边界见[云存档管理](../cloud-save-management.md)。
3. 后续可以增加按个人冒险 ID 分云槽、双人共同授权的完整房间迁移、快照缩略图和本地资源打包。当前文件沿用旧时间线的图片引用方式，不将二进制图片内嵌进存档。

## 验收重点

- 旧档 A → 开新档 B → 读取 A → 再读取 B，角色、时间线、分支和正文一致。
- 普通 JSON 与 gzip 往返；未知版本、损坏哈希、畸形树、超限文件被拒绝，当前进度不变。
- 配额不足或写入事务失败时，开新档不清空进度、保存并退出不离开房间。
- 两账号联机目录隔离；导入旧房间副本不覆盖较新快照；个人和联机文件不能串区。
- 退出取消、仅退出、保存并退出均验证；重开页面后目录仍存在；回房只调用现有鉴权连接接口。
- 桌面和窄屏检查存档按钮、列表、快照、错误提示与弹窗交互。
