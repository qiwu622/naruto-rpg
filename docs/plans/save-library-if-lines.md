# 存档库与 IF 线管理

日期：2026-09-30。延续[本地存档方案](local-save-library-v1.md)，保持原存档数据库和文件格式兼容。

## 界面与入口

存档库统一为「个人存档」「IF 线」「联机房间」三个分区，采用卡片列表。支持名称、角色、地点、房间号及线路备注搜索，按最近更新、创建时间或回合进度排序。卡片将读取或重新进入放在主操作位置，预览、改名、导出与删除保留独立按钮。

左侧时间线保留回合浏览、回溯与重 Roll。原「管理卷宗」面板移除，底部的「存档库」「IF 线管理」都打开同一个存档库；历史回合详情可直接「从此创建 IF 线」。分支起点标为「IF 起点」，不会被当作新正文回合重 Roll。

IF 线属于当前正在游玩的个人档。先读取另一份个人存档，再进入 IF 页管理它的线路。联机房间仍按账号独立管理，不提供会改写服务端房间状态的个人 IF 操作。

## 玩家操作

1. 在 IF 页选择「创建 IF 线」，填写名称、选择历史回合，可添加备注。创建后立即切换到分歧起点，原线路的后续进度保留。
2. 在线路卡片选择「切换」，恢复该线最新的状态、正文与 AI 上下文；回溯中的同一条线可以「回到最新进度」。
3. 「从此分叉」从该卡片的最新节点创建子线。「编辑线路」修改名称和备注。
4. 「设为主线」会将旧主线后续保留为一条 IF 线。当前支持直接从主线分出的线路；子 IF 需先将其上级设为主线，禁用按钮说明这个条件。
5. 删除 IF 会连同依赖它的子线删除。如果正在游玩被删除线路，恢复到最近仍存在的祖先回合。操作前的完整备份可以在个人存档页读取，找回所有线路。
6. 「保存当前个人档」包含全部线路、状态、正文、聊天上下文与日报。存档卡片可导出完整 JSON / gzip 文件；导入不会覆盖正在游玩的进度。

## 数据与失败处理

个人页「云端管理」与个人面板中的「管理云存档」打开同一个界面。可上传指定本地档或当前进度到新云槽，也可明确选择覆盖已有槽位。云下载先校验并进入本地库；选择「读取云档」时先保留当前进度。覆盖和删除云档前先下载一份完整本地备份，网络、文件或空间错误都会停止后续云端修改。云改名只更新名称，不传输或重写完整档。自动同步现在包含冷归档与全部 IF 线，继续使用独立的「默认云存档」槽位。详见[云存档接口](../cloud-save-management.md)。

- 手动 IF 创建使用独立的 `branch_anchor` 节点，保持原回合编号、状态和历史，不伪造新故事回合，也不重复添加聊天消息。
- 创建和切换先在读取副本上解压并验证可恢复状态；随后在单个 IndexedDB 事务内核对当前节点、活跃分支与源节点是否变化，并提交图关系、分支标记及元数据。成功后才恢复实时状态。
- 失败事务不会先解压写回目标节点，也不会留下半切换的分支标记。源节点变化时显示刷新重试信息。
- 聊天重建读取压缩祖先，遇到完整历史锚点后接上后续增量；不会将另一条线路的未来正文带入当前 AI 上下文。
- 个人操作复用生成中、联机中、当前页操作锁及跨标签页 Web Lock 保护。创建、切换、改名、删除和设为主线前保留完整个人备份；自动备份内容相同则去重，手动保存仍可新增副本。
- 新卡片元数据只是可选目录字段，不改变数据库版本。旧条目没有 IF 数量等字段时显示兼容说明，可正常读取和导出。
- 嵌套弹窗统一追加在页面末尾，确认框保持在存档库之上；Esc 仅关闭最上层弹窗，空名称留在表单中提示。

65 项时间线回归、6 项存档验证器、6 项节点压缩、10 项文件 codec、10 项面板和 9 项灵希游戏操作回归通过。桌面及手机截图位于 `reports/save-library-if/` 和 `reports/save-library/mobile.png`，已目视检查；320、390、768 像素宽度没有横向溢出。
