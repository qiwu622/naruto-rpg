# ADR 0002：首版联机采用单实例与 SQLite WAL

- 状态：已接受
- 日期：2026-08-21

## 背景

首版需要跨行动、回合、草稿、事件和 outbox 的短事务，又希望保持当前单机部署规模。现有 JSON 文件仓储只能串行更新单个文档，不能提供所需的唯一约束、CAS、租约和崩溃恢复。

## 决策

首版由一个 Node 进程承载 API、SSE 和逻辑任务执行器，使用本机 SQLite WAL 作为独立联机持久层。联机数据库不接入现有 JSON `server/db/index.js` 门面。

启动必须取得数据库路径的独占生命周期锁并验证 WAL、外键、同步级别、busy timeout、迁移版本和完整性；无法证明唯一写实例时拒绝启动。AI 网络调用不得持有数据库事务。

SQLite 驱动与进程锁的具体选择由 ADR 0006 冻结；最低运行版本继续兼容 Node 18。

## 后果

- 首版接受单点故障和重启时短暂断流。
- room event 与 outbox 在同一短事务写入，SSE 客户端按事件序号去重。
- 需要第二实例、滚动发布或高可用时，必须先迁移 PostgreSQL 和跨实例协调设施。
