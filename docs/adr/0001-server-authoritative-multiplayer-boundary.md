# ADR 0001：联机采用独立的服务端权威边界

- 状态：已接受
- 日期：2026-08-21

## 背景

现有单机流程会从模型正文中解析标签，再由浏览器状态管理器修改变量。这条链路无法为两名玩家提供统一授权、私密投影、并发控制、幂等重放和原子提交。

## 决策

联机领域代码放在 `server/multiplayer/`。客户端只提交意图和展示偏好；裁决、effects、记忆、日报、受众投影及最终提交全部在服务端执行。联机写入禁止调用前端 `InstructionParser`、自由变量 path、浏览器 `stateManager` 或 `TurnCommitGuard`。

模型只能提交严格结构的候选数据。客户端、模型和第三方端点提供的 room、seat、actor、revision、target、reducer 与 payer 等权威绑定字段均不可信，由服务端上下文补充或核对。

## 后果

- 单机链路可以保持兼容，但不能成为联机权威实现。
- `server/multiplayer/domain/` 不会被 `sync-public` 复制到浏览器。
- 所有联机 API 和 SSE 都必须经过成员授权与逐受众投影。
- 领域函数必须确定性运行；ID、时间、骰子和规则版本由冻结上下文传入。
