# 存档共享存储与记忆依据验证（2026-10-13）

本轮是本地开发，未发布网站、GitHub 或 Android 安装包。

## 行为与兼容

- 存档库的「无损整理」创建完整新副本，保留全部回合、IF 线、正文、变量、记忆以及原始存档；不会自动切换或删除原档。读新副本确认无误后，玩家可自行导出、管理原档。
- 重复快照、维护前状态和旧式完整聊天历史使用不可变的共享数据块。每回合保留完整数据块目录，不依赖前一个回合，避免删线、重推或修订父节点破坏子节点。近期 20 个节点直接读取，其余按需恢复。浏览回合窗口仍由玩家设置，默认 100。
- 新的冷归档逐节点写入；已有冷归档不在启动时全量迁移。数据库由 v2 加到 v3，只增加数据块仓库，不在升级事务中改写旧记录。旧版程序不能直接打开更高版本的数据库；导出的 JSON/gzip 保持原有完整格式，不携带本地数据块引用。
- 新节点与其数据块在同一事务发布。整理副本写入后重新读取、验证块哈希和完整内容，才推进断点；所有回合通过校验后才出现在可读存档列表。磁盘不足、主动暂停或关闭线程可续做；未完成任务会保护其源存档，直到完成或由玩家清理。
- 空间管理显示回合记录、共享数据、未完成副本和可清理数据的估算。共享块只计一次；浏览器实际占用受内部压缩和其他站点数据影响。清理同时扫描当前档、所有完整存档和未完成任务，事务内删除无引用块。
- 「本轮记忆依据」展示本地记忆模块实际纳入预算的分组与已知章节/事件来源，提供到现有修订编辑器的定位入口。不捏造旧记忆的原始回合，不持久化本次查看记录，读档/修订后清空。后续预设处理可能进一步裁剪上下文。
- 向量记忆仍可选、默认关闭。记录依据本身不增加模型请求，也不改变原有记忆提示词。
