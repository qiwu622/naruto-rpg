# v3.6.5 单节点 32 MiB 读取限制热修复

日期：2026-10-15。网页版本 3.6.5，构建 `261015-node-read-fix`。安卓安装包仍为 3.6.4，本次未发布 GitHub 或安装包。

## 原因和修复

正式站、测试站及本地仍有单节点默认 32 MiB 解压上限；写入流程没有对应限制。正常长档能够保存较大的压缩快照，回看、恢复、导出或救援时却被读取器拒绝。此前取消整份导入文件的 200 MiB 限制并未覆盖这一独立读取器。

使用含 36 MiB UTF-8 记忆的正常节点，修复前稳定复现截图原文“时间线节点解压后超过 32 MiB 上限”。默认节点读取改为不设固定容量上限；gzip 编解码复用分块 JSON 读写，避免将完整节点拼成一个额外大字符串。显式限额仍校验并按 UTF-8 字节计数；损坏 gzip、JSON 和存档格式检查保留。

本地待发布的共享块存储同样使用修正后的默认值；这部分没有随网页热修复上线。正式发布包从当前线上代码构建，只应用节点编解码修复、缓存版本、网页构建版本和公告；未发布本地变量、记忆、去重存储等其他改动。
