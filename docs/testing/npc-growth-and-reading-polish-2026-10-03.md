# NPC 成长与阅读界面精修验收

日期：2026-10-03。仅本地修改；不发布网站、GitHub 或安卓安装包。

## 问题与修复

通过真实 `instructionParser → MessagePipeline → relationshipSystem` 复现：已有下忍查克拉上限 150、当前值 40，收到上限 240、当前值 100 的增量后，原实现得到 160/40；只训练一个忍术也会覆盖其余忍术。问题出在 NPC 归一化，而非单纯界面缺少显示。

- 忍阶数值范围只用于缺失信息的初始参考，不再在每次写入、读取时截断已记录的成长。属性沿用玩家 0–9999、熟练度 0–100 的有效范围。
- 明确给出的当前资源可以恢复；省略当前值保留伤势、消耗和零值，上限增加不会自动回满。
- 忍术按名称/正史 ID 增量合并，新查克拉属性与旧属性合并。未提及的能力和空列表不会清空已有记录。
- 清理旧英文别名与中文字段竞争的问题，避免旧值影响战力计算。
- 正文与独立变量、Agent 变量运行时均收到成长记录指引；不改写用户导入预设，不强制每回合产生成长。
- 已打开的 NPC 档案同步更新战斗数值、忍术、综合战力；保留滚动和肖像编辑区域，读档/重置时关闭旧档案并解除监听。

历史上已经被旧逻辑截断或覆盖的数据不能凭空还原；本次保留仍存在于存档中的数据，并正确接收后续有剧情依据的更新。

## 视觉实现

先使用内置 ImageGen 生成参考图，再精修现有界面。主要样式修改集中在 `css/layout.css` 与 `css/components/panel.css.js`，没有更换游戏壁纸或重做页面结构。

- 正文区域叠加柔和深墨遮罩，顶栏与侧栏降低背景染色。
- 输入框使用细描边与柔和焦点状态，主按钮改为朱红色；去除姓名、综合战力、进度条的常驻闪光。
- 侧栏分区与标签层级更清晰，精神力/体力数值保持完整；手机输入区避开底部状态栏。
- 手机 NPC 档案缩小头像与姓名区，三项关系数据并排呈现，减少到达战斗属性所需的滚动。
- 修复手机角色面板的关闭按钮：此前只派发 DOM 事件，主界面监听的是事件总线。复现点击后面板仍打开，再补齐事件总线通知并通过真实主界面回归。
