## 发布流程与后续公告

正式站先准备新版依赖，再备份与切换单写者服务；测试站使用 `--frontend-only`。安装器在就绪检查短暂失败时等待恢复，成功后留下回执与永久备份；未回滚或覆盖运行数据。安卓发布独立使用验证过的设备回执和安全区证据，覆盖两个网站的既有下载入口。

`sync-public` 根据当前版本的 `docs/releases/v<version>-discord.md` 与 CHANGELOG 自动生成网站公告；部署包及安装器校验公告版本。AGENTS.md 已记录“每次正式站发布同步网站公告”的要求。后续发布应更新版本、日期、说明和升级注意事项，再核对线上公告。

## 验证边界

本机直接访问正式域名的 TLS 握手仍失败。线上浏览器及 Android HTTPS 检查通过仅允许正式域名的临时 SSH CONNECT 通道进行，保留端到端 TLS 证书校验；安装器同时在服务器上验证真实公网域名资源。该记录不等同于所有玩家网络均可达。没有额外付费模型调用；远端完整 Discord 授权需要玩家使用自己的账号确认。

本地详细证据位于 `reports/release-v3.6.0/` 与 `reports/android/release-v3.6.0-final/`；报告、密钥、运行数据库及安装包构建目录不进入 Git 提交。
