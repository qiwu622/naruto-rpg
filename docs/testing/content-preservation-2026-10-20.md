# 内容保留与软约束修复

日期：2026-10-20。仅本地修改，不发布网站、GitHub 或 Android 安装包；版本保持 3.7.1。保留工作区此前所有未发布修改。旧的复现记录见 `content-constraints-audit-2026-10-20.md`。

## 行为

- 正文：标签名称按协议单词边界识别，普通 `secretary_dialogue` 不再被误删；传统回映必须有明确开头和独立结束行，引用结束标记不删除前文。移除“极其/共犯”的无条件替换。合法 JSON 中的文字标签是数据，保留原文；解析器也不再把超过 24 层的嵌套字段静默替换为 null。真实外层思考/私有容器继续隔离，不把隐藏指令执行为公开状态。
- 预设：缺少 think、单根或展示尾部只报告兼容提示；变量 JSON/路径/类型仍独立校验。合法机器尾部允许追加，展示格式不能否决已完成的正文和变量。同一回合相同的容器提示不重复弹出。
- 日报：字数、条数、图标、等级排序和附加字段为排版建议，完整保存内容、空白与扩展字段。结构类型错误仍进入原有定向修复，已校验变量不重做。联机公开来源矩阵与实际日报条目数逐一对应，仍拒绝未公开引用。
- 记忆：180/240/900 字等写入截断及置顶、NPC 笔记、线索、事件的数量淘汰已移除。活跃事实超出窗口会完整移入归档，归档超出提醒数量也不删除。每次真实更新追加完整 `source_records`，只记增量更新而不递归复制整份历史；相同回合重复提交相同更新不会重复追加。旧档首次写入先保存现有内容基线。原始记录不参与自动提示词拼装。
- 整理：滚动小结和模型输入仍按预算选取，均为派生视图；压缩前完整回合块及原始更新均可追溯。章节原文不再只保留前 6000 字，AI 升级章节/卷摘要后仍保留 raw，并记录已整理状态以免反复调用。记忆纠错不再因 2000 字或 100 条门槛拒绝保存，纠正/否定/撤销的分支隔离与持久化保护继续生效。
- 界面：记忆卷宗新增“原始记忆记录”，按页加载、按需展开完整 JSON；不执行其中的 HTML。归档数量超出建议值显示提示。预设选项长于 1000 字、数量多于 64 条仍可选择；沙箱点击桥和灵希行动提案/批准/主输入链均传递完整行动。
- 正则与补充提示词：正则输入、输出、脚本数量超过建议值只警告，仍处理全文和全部脚本；灵希自定义补充取消 8000 字截断。
- 存档：普通记忆文字包含 literal `blob:` 或 `data:image/...` 示例时不再因此被整条清空；实际媒体字段、危险对象键和二进制持久化限制保持原有处理。

## 兼容性

上下文预算不等于存储上限：仍按当前配置只发送本轮相关内容，并保留召回依据。用户明确纠正、删除、结束任务和状态变迁仍可更新活跃视图；原始记忆更新可在记录中查看。旧版本已经删掉且不在任何原档/时间线中的文本无法凭空恢复。

世界书开关与关键词触发、联机受众授权、凭据隔离、SSRF/危险路径防护、HTML 脚本沙箱、未选择选项不进入事实记忆等逻辑继续保留。不调用真实外部模型，不使用用户密钥，不读写真实玩家数据。
