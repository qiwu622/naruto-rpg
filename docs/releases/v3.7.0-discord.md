# 🍃 忍者手记 v3.7.0 更新公告

**2026-10-15 · 变量、时间与大档优化**

## 本次更新

- **变量更可靠**：修复自检吞掉更新、标签顺序错乱和部分漏写，减少无效重试。
- **时间正常推进**：支持精确时刻、跨日跨年；未选选项和未来约定不提前发生。
- **大档无损整理**：保留完整原档，生成共享存储副本；支持暂停、断点续做和空间管理。
- **记忆依据可查看**：查看本轮实际纳入的记忆并定位修订；向量记忆仍默认关闭。
- **安卓同步更新**：包含 32 MiB 读取修复，可在客户端查看公告、下载并覆盖安装。

## 升级说明

> 网页请在原浏览器刷新；安卓覆盖安装即可，**无需卸载或重新开档**。
> 旧档升级保留原始记录。无损整理不会自动删除原档，保留原档期间总占用不会立即减少；JSON/gzip 导入导出继续兼容。升级后的本地数据库请使用新版程序读取。
