# 🍃 忍者手记 v3.7.4 更新公告

**2026-11-20 · 设置与世界书重构 · 全局按钮美学统一 · 大存档防崩溃加固**

## 本次更新

- **世界书内置条目可自由编辑**：新增「墨印卷册」世界书编辑器，支持对内置条目单条开关、本地改写与独立恢复默认，支持按「全部 / 已改 / 已关闭 / 蓝灯常驻」快速筛选，自定义条目导入导出继续兼容。
- **设置中心与全站按钮质感统一**：统一 5 套深/浅视觉主题（含和纸浅色模式）与实时阅读预览；全站设置页、编辑器、弹窗、存档库、联机面板、创角及公告/救援页按钮重构为「墨印漆作」暗漆双层体系，移除刺眼荧光橙光晕与廉价渐变。
- **大存档防崩溃与独立救援加固**：新增大存档流式分块导入/导出以降低内存峰值、连续启动异常自动高亮「存档救援」入口、启动后自动申请浏览器持久化存储并错峰维护、超大档自动节流云同步；同步升级独立救援页、可选外置备份及安卓原生存档保险库与启动崩溃守护。
- **主预设微调**：默认主预设第 24 条「执笔者定位」改为常规 `system` 指令，避免部分模型出现多余确认或复述预设（自定义主预设不受影响）。

## 更新方式

> 正式站网页端与安卓客户端 **v3.7.4** 已同步发布。网页端在原浏览器刷新页面（或点击顶部更新条「立即刷新」）即可生效；安卓端可在客户端内检查更新或下载覆盖安装（请**切勿先卸载旧版**），**无需清除数据或重新开档**，现有本地与云端存档完全保留兼容。
