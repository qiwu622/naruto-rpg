# 🍃 忍者手记 v3.6.4 更新公告

## 本次更新

- **大档优化**：按需读取历史，后台逐条保存、导出，减少长档卡死。
- **旧档救援**：先保留完整原档，再选择恢复点生成续玩副本；失败或取消不覆盖原档。
- **回合数自选**：历史每页数量、续玩副本保留数量均可设置，默认 **100**。
- **App 内更新**：在客户端查看公告、下载进度并直接安装，无需去官网找安装包。
- **可选向量记忆**：默认关闭；自行开启后辅助召回，网络失败仍可继续游玩。
- 同步此前大档导入、保存忙碌误报、流式滚动和思维链默认折叠修复。

> **旧存档兼容，无需重新开档。** 完整旧回合和 IF 线保留在原档中，轻量副本只保留所选范围。
